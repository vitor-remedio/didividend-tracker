# Monitor de Proventos

Aplicação pública para acompanhar proventos anunciados por empresas e fundos imobiliários negociados na B3.

## Status

MVP em desenvolvimento. A interface inicial utilizará dados demonstrativos; nenhuma integração financeira ou persistência está configurada ainda.

## Stack planejada

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase / PostgreSQL (etapa futura)
- HG Brasil API (após prova de conceito)
- Vitest e Playwright
- Vercel

## Desenvolvimento local

A configuração de desenvolvimento será documentada após a criação da fundação Next.js.

## Dados

Os dados apresentados no MVP inicial são fictícios e servem exclusivamente para validar a interface. Não devem ser utilizados para decisões de investimento.
